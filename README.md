# Go Rogue

Пошаговая roguelike-игра на Go в духе классической Rogue: случайные подземелья, терминальный интерфейс и режим от первого лица на основе ray casting.

Проект разработан совместно с [SophieSilver](https://github.com/SophieSilver) в рамках командного задания Go Bootcamp Школы 21.

Исследуйте 21 уровень, сражайтесь с монстрами, собирайте снаряжение и ищите путь вниз. Выход с последнего уровня завершает прохождение победой, а количество собранных сокровищ определяет место в таблице рекордов.

## Возможности

- Процедурная генерация комнат и соединяющих их коридоров.
- Пошаговые бои с расчётом попадания и урона по характеристикам персонажей.
- Шесть типов противников с разным поведением: зомби, вампир, привидение, огр, змей-маг и мимик, маскирующийся под предметы.
- Инвентарь: оружие, броня, еда, эликсиры, свитки и ключи.
- Запертые двери с красными, зелёными и голубыми ключами.
- Туман войны и исследование карты в пределах видимости.
- Подстройка сложности по глубине подземелья, характеристикам героя и боевой статистике.
- Переключение между видом сверху и псевдо-3D с текстурированными стенами и мини-картой.
- Сохранение прохождения и таблицы рекордов в JSON.

## Требования

- Go 1.25.5 или новее — версия указана в `src/go.mod`.
- Компилятор C, `pkg-config` и библиотеки разработки ncurses: интерфейс использует `goncurses` через CGO.
- Терминал с поддержкой цветов размером не менее **80 столбцов × 24 строк**.

Для Ubuntu / Debian системные зависимости устанавливаются командой:

```bash
sudo apt install build-essential pkg-config libncurses-dev
```

## Запуск

Из корня репозитория:

```bash
cd src
go run ./main
```

Go загрузит зависимость `github.com/gbin/goncurses`, указанную в `go.mod`.

Чтобы собрать исполняемый файл и запустить его из той же директории:

```bash
go build -o rogue.bin ./main
./rogue.bin
```

При первом запуске введите имя игрока и нажмите Enter. Если сохранение уже существует, игра предложит продолжить его: `Y` — загрузить, `N` — начать заново. Интерфейс игры — на английском языке.

## Как играть

Передвигайтесь по карте с помощью `WASD`. Для атаки сделайте шаг в сторону врага. Предметы подбираются при наступании на них, если в рюкзаке есть место. Для открытия цветной двери нужен ключ соответствующего цвета.

На клетке лестницы нажмите `V`, чтобы перейти на следующий уровень. Если в строке событий накопились сообщения, просмотрите их пробелом, чтобы продолжить действия.

## Управление

Используйте английскую раскладку. Буквенные команды работают в обоих регистрах.

| Клавиша | Действие |
| --- | --- |
| `W` / `A` / `S` / `D` | Движение вверх / влево / вниз / вправо |
| `.` | Пропустить ход |
| `V` | Спуститься по лестнице |
| `I` | Открыть или закрыть рюкзак |
| `H` | Выбрать оружие |
| `G` | Выбрать броню |
| `J` | Съесть еду |
| `K` | Выпить эликсир |
| `E` | Прочитать свиток |
| `T` | Выбросить предмет |
| `1`–`9` | Выбрать предмет в меню |
| `0` | Выбрать слот надетого снаряжения |
| `L` | Таблица рекордов |
| `O` | Переключить вид сверху / от первого лица |
| `M` | Показать или скрыть мини-карту в режиме от первого лица |
| `?` | Справка по управлению |
| Пробел | Просмотреть сообщение или закрыть информационный экран |
| Обратная кавычка (&#96;) | Назад / отмена выбора |
| `Q` | Выйти с сохранением незавершённой игры |

В режиме от первого лица `W` и `S` перемещают вперёд и назад, а `A` и `D` поворачивают персонажа.

## Сохранения и рекорды

Прогресс сохраняется при переходе на следующий уровень и при выходе через `Q`. При смерти или победе сохранение прохождения удаляется, а результат попадает в таблицу рекордов.

Файлы создаются в текущей рабочей директории:

| Файл | Содержимое |
| --- | --- |
| `rogue_game.save` | Состояние текущего прохождения в JSON |
| `rogue_leaderboard.save` | Результаты прохождений в JSON |

Запускайте игру из одной и той же директории, чтобы она находила ваши сохранения. Файлы `*.save` и собранный `*.bin` исключены из Git через `.gitignore`.

## Структура проекта

```text
.
├── README.md
├── .gitignore
├── LICENSE
└── src/
    ├── go.mod
    ├── go.sum
    ├── main/                  # Точка входа
    ├── domain/                # Правила игры и состояние мира
    ├── data/                  # Сохранение и загрузка JSON
    └── presentation/
        ├── controller/        # Игровой цикл
        ├── input/             # Обработка клавиатуры
        └── render/            # Терминальный интерфейс, 2D и псевдо-3D
```

Игровая логика отделена от ввода, отображения и файлового хранилища. Слой `domain` описывает генерацию уровней, движение, поведение противников, бой, инвентарь и видимость. Для сохранения он использует интерфейс `SaveLoad`, реализованный в слое `data`. Слой `presentation` связывает действия игрока и состояние мира с `goncurses`.
